# AccelBoost AI 🚀

A modern, high-performance landing page for **AccelBoost AI** — an AI marketing platform orchestrating Paid Ads, SEO, and GEO (Generative Engine Optimization) on flat monthly plans.

---

## ✨ Features

- **Interactive Showreel Hero**: Multi-scene canvas and SVG animation reel showcasing live marketing metrics (ROAS, organic growth, GEO citations).
- **Interactive Light / Dark Mode Toggle**: Expanding circular clip-path transition matching the navigation menu wave.
- **Dynamic Bento Grid**: Highlighted metric cards featuring animated circular SVG gauges and live data bars.
- **Service Platform Explorer**: Expandable interactive service cards (Paid Ads, SEO, GEO, Reporting, Automation).
- **Pricing Switcher**: Seamless toggle between Monthly and Annual (−20%) tiers with real-time numeric count transitions.
- **Kinetic Watermark Footer**: Interactive character-by-character bounce and progressive solid deep-orange illumination on hover.
- **Fully Responsive**: Optimized for all viewports from 320px mobile screens to ultra-wide desktop monitors.

---

## 🛠️ Tech Stack

- **HTML5 & CSS3**: Pure modern CSS (Custom Properties, Flexbox, Grid, Clamp, View Transitions API).
- **Vanilla JavaScript**: Lightweight, zero external runtime framework dependencies.
- **Typography**: [Bricolage Grotesque](https://fonts.google.com/specimen/Bricolage+Grotesque), [DM Sans](https://fonts.google.com/specimen/DM+Sans), and [DM Mono](https://fonts.google.com/specimen/DM+Mono).

---

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or host with GitHub Pages.

```bash
# Clone the repository
git clone https://github.com/<your-username>/accelboost-ai.git

# Navigate into the project folder
cd accelboost-ai

# Open in browser
open index.html # On macOS
start index.html # On Windows
```
